    Không có ứng dụng nào khớp. Thử từ khác nhé.

    Cài trong 3 bước

    1. 1

      Tải và giải nén

      Bấm Tải về để lấy file .zip, chuột phải → Giải nén tất cả. Giữ lại thư mục này, đừng xoá.

    2. 2

      Bật chế độ nhà phát triển

      Gõ chrome://extensions vào thanh địa chỉ, bật Chế độ dành cho nhà phát triển ở góc phải.

    3. 3

      Tải tiện ích lên

      Bấm Tải tiện ích đã giải nén, chọn thư mục vừa giải nén. Biểu tượng tiện ích hiện trên thanh công cụ.

    1. 1

      Tải file về

      Bấm Tải về ở ứng dụng bạn cần. File nằm trong thư mục Downloads.

    2. 2

      Mở file

      Bấm đúp vào file. Nếu Windows hiện màn hình xanh “Windows protected your PC”, chọn More info → Run anyway.

    3. 3

      Dùng luôn

      Ứng dụng mở ra là dùng được. Mỗi app có hướng dẫn ngắn trong phần Chi tiết.

    Hỏi đáp

    Vì sao Windows cảnh báo khi mở file?

    Windows cảnh báo với mọi ứng dụng chưa mua chữ ký số (một loại giấy chứng nhận trả phí hằng năm), không có nghĩa file có hại. Chọn More info → Run anyway để mở.

    Làm sao biết file tải về không bị sửa?

    Mỗi app có mã SHA-256 trong phần Chi tiết. Mở PowerShell ở thư mục chứa file và gõ Get-FileHash ten-file.exe — kết quả phải trùng mã trên trang.

    Ứng dụng có gửi dữ liệu của tôi đi đâu không?

    Không. Các app ở đây xử lý ngay trên máy bạn. Nếu app nào cần mạng, phần Chi tiết sẽ ghi rõ.

    Gỡ ứng dụng thế nào?

    Ứng dụng Windows phần lớn chỉ là một file, không cần cài — xoá file đi là xong. Nếu đã bật “Chạy cùng Windows”, tắt công tắc đó trong app trước khi xoá. Tiện ích Chrome: vào chrome://extensions, bấm Xoá ở tiện ích đó.
